# ASK Pen Plotter Gcode

An Inkscape extension that exports drawings as G-code for pen plotters. It supports custom pen up/down commands, separate drawing and travel speeds, inside/outside offset, line fill, and path-order optimization.

## Requirements

- Inkscape 1.0 or newer
- A plotter that accepts standard G-code (GRBL or Marlin)

## Installation

1. Download the file.
2. In Inkscape, open **Edit > Preferences > System** and find the **User extensions** folder.
3. Extract the downloaded file into that folder.
4. Restart Inkscape.

The extension appears at **Extensions > ASK Pen Plotter > Export Gcode**.

## How to use

1. Set the document size to match your plotter's drawing area (**File > Document Properties**), and work in millimetres.
2. Draw or import your artwork.
3. Convert any text to paths: select it and choose **Path > Object to Path**. Text that is not converted is skipped.
4. Optionally select the objects you want to plot. If nothing is selected, everything visible is exported.
5. Open **Extensions > ASK Pen Plotter > Export Gcode**.
6. Choose the output file, check the settings (see below), and click **Apply**.
7. A summary shows the number of paths, drawing distance, estimated time and plot area. Check that the plot area fits your machine.
8. Home your plotter so the pen is at the bottom-left corner of the drawing area, then send the `.gcode` file with your usual sender (for example Universal G-code Sender).

Run a first test with the pen lifted off the paper to confirm direction and size.

## Settings

### Pen & Speed

| Setting | Default | Description |
|---|---|---|
| Output file | `plot.gcode` | Where the G-code is saved. |
| Pen up command | `M3 S0` | Sent to lift the pen. |
| Pen down command | `M3 S180` | Sent to lower the pen. |
| Wait after pen up/down | 200 ms | Pause so the servo finishes moving before the plotter moves. |
| Dwell format | Seconds (GRBL) | GRBL reads `G4 P` in seconds, Marlin in milliseconds. |
| Drawing speed | 1500 mm/min | Speed while the pen is down. |
| Travel speed | 4000 mm/min | Speed while the pen is up. |

### Mode

| Mode | What it does |
|---|---|
| Pen Plotter: (no offset) | The pen centre follows the path exactly. |
| Pen Plotter: (path inside) | Closed shapes are shifted inward by half the pen width. |
| Pen Plotter: (path outside) | Closed shapes are shifted outward by half the pen width. |
| Pen Plotter: (lines fill) | Closed shapes are filled with parallel lines. |

Mode settings:

| Setting | Default | Used by |
|---|---|---|
| Pen width | 0.5 mm | Path inside / outside |
| Line spacing | 0.5 mm | Lines fill. Use the pen width for a solid fill. |
| Line angle | 45° | Lines fill |
| Also draw the outline | On | Lines fill | 

### Geometry

| Setting | Default | Description |
|---|---|---|
| Export only selected objects | On | Applies only if something is selected. |
| Flip Y axis | On | Puts the origin at the bottom-left of the page. Turn off if the plot is mirrored. |
| Optimize path order | On | Reorders paths to reduce pen-up travel. |
| Return to X0 Y0 | On | Sends the pen home when finished. |
| Curve tolerance | 0.05 mm | Curves become short straight lines. Smaller is smoother but makes bigger files. |
| Scale | 100 % | Resizes the plot. |
| X / Y offset | 0 mm | Shifts the plot on the bed. |

## Example output

```gcode
; Generated by Inkscape Pen Plotter G-code Export
; Mode: Pen Plotter: (no offset)
; Paths: 1
G21 ; units: mm
G90 ; absolute positioning
M3 S0 ; pen up
G4 P0.200
G0 X10.000 Y10.000 F4000
M3 S180 ; pen down
G4 P0.200
G1 X50.000 Y10.000 F1500
G1 X50.000 Y50.000
M3 S0 ; pen up
G4 P0.200
G0 X0 Y0 F4000 ; return home
; end
```

## Notes and limitations

- Text must be converted to paths first.
- Hidden layers and hidden objects are skipped.
- Open paths cannot be offset or filled; they are drawn on the line.
- Lines fill hatches every closed shape, whether or not it has a fill colour in Inkscape. Holes inside a shape are left unfilled.
- The inside/outside offset is simple: it works well for pen-width amounts, but very tight inward curves can produce tiny loops.
- Images (bitmaps) are ignored. Trace them first with **Path > Trace Bitmap**.

## Troubleshooting

| Problem | Fix |
|---|---|
| Plot is mirrored top to bottom | Turn off **Flip Y axis**. |
| Line starts are missing or smeared | Increase **Wait after pen up/down**. |
| Pauses are far too long or too short | Change **Dwell format** to match your firmware. |
| Pen moves the wrong way (up when it should be down) | Swap the pen up and pen down commands. |
| Plot is the wrong size | Check the document units and size in **Document Properties**, or adjust **Scale**. |
| Extension is missing from the menu | Check both files are in the User extensions folder and restart Inkscape. |
